# /poui-specialist:connect

Conecta um componente Angular (gerado pelo plugin) aos dados reais do Protheus, substituindo mocks por chamadas HTTP reais, configurando o proxy e gerando o contrato TLPP quando necessário.

## Sintaxe

```bash
/poui-specialist:connect <ComponentClass> --module <module>
```

## Exemplos

```bash
# Conectar componente de divergências ao Protheus
/poui-specialist:connect DivergenciasCartaoComponent --module financeiro/divergencias-cartao

# Conectar lista de títulos
/poui-specialist:connect TitulosListComponent --module financeiro/titulos-list

# Conectar cadastro de parceiros
/poui-specialist:connect ParceirosComponent --module faturamento/parceiros
```

## Formato mínimo do pedido

```
/poui-specialist:connect DivergenciasCartaoComponent --module financeiro/divergencias-cartao

PROTHEUS: http://192.168.1.10:8086
ENDPOINT: GET /rest/api/custom/v1/financeiro/divergencias  (já existe)
AUTH: Basic — usuário/senha no proxy
MOCK A REMOVER: src/app/core/interceptors/mock-divergencias.interceptor.ts
```

## Processo (9 passos)

1. **Diagnóstico de mocks** — identifica interceptors, dados hardcoded e service mocks ativos
2. **Coleta de dados de conexão** — solicita URL Protheus, endpoint, credenciais e mock a remover
3. **Atualização do proxy** — configura `proxy.conf.json` com o host Protheus real
4. **Substituição do service** — reescreve o service para apontar ao endpoint real
5. **Desativação de interceptors** — remove ou comenta o interceptor de mock
6. **Geração de contrato TLPP** — cria skeleton WsRestFul se o endpoint não existir
7. **Atualização de specs** — ajusta os testes para usar `HttpTestingController` com a URL real
8. **Verificação de build** — executa `ng build` e corrige erros TypeScript/template
9. **Confirmação** — lista todos os arquivos alterados com seus caminhos absolutos

## Quando usar

Use `/connect` após gerar um componente com `/generate` e querer substituir os dados mockados por uma chamada real ao Protheus:

```bash
# 1. Gerar o componente com dados mock
/poui-specialist:generate page-list Titulos --module financeiro

# 2. Conectar ao Protheus real
/poui-specialist:connect TitulosListComponent --module financeiro/titulos-list
```
