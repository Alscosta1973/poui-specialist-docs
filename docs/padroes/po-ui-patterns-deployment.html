Guia de Deploy — Angular + PO-UI + Protheus

Cobre: build de produção, análise de bundle, opções de hospedagem, configuração CORS no Protheus, autenticação em produção e deploy dentro do SmartClient/iframe.

1. Build de Produção

Comando

Saída em dist/<project-name>/browser/ por padrão do builder @angular/build:application (Angular 17+), que reserva a raiz de dist/<project-name>/ para uma eventual build SSR. Projetos criados via /poui-specialist:scaffold configuram outputPath.browser: "" em angular.json, então a saída já vem achatada direto em dist/<project-name>/ — sem a subpasta browser/. Isso é necessário porque o Protheus (FWCallApp/AjustaIndex) espera index.html na raiz da pasta publicada; veja deploy-protheus.md seção 2.

A build gera:

  • Minificação de JS/CSS
  • Tree-shaking de imports não usados
  • Hashing de nomes de arquivo (main.abc123.js) para cache-busting automático
  • Source maps desabilitados por padrão

2. Análise de Bundle

Opção A — webpack-bundle-analyzer

Abre browser com mapa visual de tamanho por módulo. Identificar:

  • @po-ui/ng-components importado inteiro (verificar se barrel imports desnecessários)
  • @totvs/protheus-lib-core — pode ser grande; usar somente o necessário
  • Módulos duplicados (ex: rxjs em múltiplas versões)

Opção B — source-map-explorer (sem plugin extra)

Verificar lazy loading

4. Configuração CORS no Protheus AppServer

Em desenvolvimento, o proxy.conf.json evita CORS. Em produção há três estratégias:

Estratégia 1 — Mesma origem (sem CORS)

Angular e AppServer na mesma URL base:

  • Angular em http://server:8080/
  • REST em http://server:8080/rest/api/...
  • Sem problema de CORS — recomendado para produção

Configurar nginx como proxy reverso:

Estratégia 2 — Cabeçalhos CORS no ADVPL

Se Angular e AppServer ficarem em origens diferentes, adicionar CORS headers no endpoint TLPP:

Preflight OPTIONS: Protheus responde automaticamente a OPTIONS com 200; verificar se os headers CORS aparecem também na resposta OPTIONS.

Estratégia 3 — Parâmetro MV_CORSORI

Alguns builds do Protheus suportam o parâmetro MV_CORSORI para configurar origens permitidas sem alterar código ADVPL. Consultar documentação da versão específica.
