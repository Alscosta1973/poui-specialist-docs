3. po-table horizontal scroll in side-by-side panels

Symptom: When two po-table components are placed side by side (flex:1 each), each table generates a horizontal scrollbar even though the specified p-width values seem reasonable.

Root cause: po-table adds an internal selectable-column (po-table-column-selectable) of 56px that is NOT represented in PoTableColumn[]. This hidden 56px pushes the table wider than its container.

8. po-table: programmatic $selected: false does not cancel a just-committed selection

Symptom: Quando (p-selected) dispara e você quer rejeitar a seleção, definir $selected: false de forma síncrona não tem efeito. A linha permanece visualmente selecionada.

Root cause: po-table adiciona a linha ao seu selectedRows interno antes de despachar o evento (p-selected). Qualquer mudança síncrona em $selected: false é processada no mesmo ciclo de CD — mas o estado interno do po-table já tem a linha, então a desincronia persiste.

Nota: O setTimeout(0) causa um flash visual de ~1 frame onde a linha parece selecionada antes de reverter. Imperceptível na prática mas inevitável com a API atual de (p-selected).

11. PoTableDetail — width property not supported (TS2353)

Symptom: TS2353: Object literal may only specify known properties, and 'width' does not exist in type 'PoTableDetailColumn'.

Root cause: PoTableDetail.columns usa o tipo interno PoTableDetailColumn, subconjunto de PoTableColumn que não inclui width. width só é válido em colunas master.

Fix: Remover width das colunas de detail. Somente property, label, type e format são suportados.

16. po-table: colunas numéricas/monetárias devem usar type correto (descoberto 2026-06-26)

Symptom: Valores numéricos aparecem alinhados à esquerda, sem formatação de milhar ou decimais.

Root cause: Colunas sem type específico são renderizadas como string — sem alinhamento nem formatação automática.

Fix: Sempre definir type: 'number' ou type: 'currency' em colunas numéricas.

Regras de tipo por padrão de nome de campo:

Padrãotypeformat
valor*, preco*, total*, saldo*, desconto*, taxa*currency'BRL'
qtd*, quantidade*, qtde*number'1.0-2'
perc*, percent*, porcent*number'1.2-2'
data*, dt*date'dd/MM/yyyy'

Campos de código alfanumérico (ex: '001', 'NF001') → não usar type: 'number'.
